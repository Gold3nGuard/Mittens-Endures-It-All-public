# Mittens-Endures-It-All

## How to Play Instructions

### Windows

1. Download the [latest release](https://github.com/Gold3nGuard/Mittens-Endures-It-All-public/releases/latest)
2. Unzip the archive to a folder of your choice.
3. Go into the folder `MittensEnduresItAll-v0.2.4-pc`
4. Run `MittensEnduresItAll.exe`
5. Enjoy!

## About
"Mittens Endures It All" is a visual novel dating sim written in Ren'Py. It's basically a Lumity retelling of the classic omorashi game "Melissa Explains It All".

## Inspiration

- The primary source of inspiration for this game is ["Melissa Remake" by WielkiJa](https://www.omorashi.org/files/file/14514-melissa-remake-beta/)
- A lot of my code is a direct translation from [Pisikak's "Melissa Endures It All" source code](https://www.omorashi.org/files/file/9194-melissa-endures-it-all/)
- And the original game that inspired all of us is ["Melissa Explains It All" by drw](https://onlinemel.angelfire.com/)

## Note About Controllers

I did my best to add controller support to this game. If you use a generic controller, it is best to use XInput mode. See your controller manual for details about how to toggle XInput mode. 

### Known controller issues:

I use a Game Sir Nova Lite controller. Using the settings I normally use for steam, this controller interprets right joystick input as if it was left+right trigger input and going back to deadzone doesn't reset the inputs, it keeps the triggers as if they were permanently being pressed. Switching to XInput mode fixes this. To switch your Game Sir Nova Lite controller to XInput mode, hold down the menu and view buttons for two seconds (these are the two buttons immediately to the left and right of the circular lit up home button with the Game Sir logo on it). This toggles on XInput mode. 

If you use Linux like me, the XInput mode inverts the joystick for the Game Sir Nova Lite controller. You're using Linux, so you can Google how to fix that if that bothers you.
